# 本地文件指代解析

## 适用条件

用户没有再次给出完整路径，而是使用“刚才的文档”“上面那些文件”“前两个笔记”等指代表达，并且当前任务需要把明确路径交给 Learning Agent。

## 操作步骤

1. 从 Main Agent 当前目标中已经注入的短期记忆寻找文件路径、文件名、出现顺序和用户之前的选择。
2. 如果候选数量、路径和顺序唯一，直接整理为绝对路径列表，不做多余读取。
3. 如果需要区分同名文件或核对少量内容，调用 `read_local_text_file`；只使用预览进行消歧。
4. 将确认后的绝对路径、顺序、合并目标、期望输出形式完整写入 `delegate_note_agent` 的目标。
5. 候选仍不唯一，或短期记忆中根本没有路径时，向用户确认，不得猜测。

## 边界和异常

主 Agent 不提取 docx、PDF、图片、音频或视频内容；这些格式直接把路径交给 Learning Agent。文件越过允许根目录、格式不支持或体积超限时，不要绕过安全限制。读取文件不会修改源文件。

## 完成标准

最终应得到一组无歧义、有顺序的绝对路径及清晰任务说明，并成功交给正确的 Sub-Agent。
