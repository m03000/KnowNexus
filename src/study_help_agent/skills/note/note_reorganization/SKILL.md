# 已有笔记重组

## 适用条件

输入是多篇已有本地文本笔记，用户希望统一术语、消除重复、调整章节或形成一份更完整的新笔记。原笔记只作为来源，新结果不得覆盖原文件。

## 标准步骤

1. 确认笔记路径、先后顺序、目标读者和重组主题。
2. 使用 `merge_text_files` 保留每篇笔记的文件边界和来源元数据。
3. 把合并 Artifact 交给 `build_learning_note`，要求从全局审查结构，而不是沿用每篇笔记各自合理但整体割裂的目录。
4. 检查重复概念是否合并、冲突观点是否保留来源差异、术语是否统一、示例与结论是否仍有上下文。

## 内容边界

最大限度保留知识价值，但可以删除机械重复、重排章节、合并同义段落和重命名标题。不能把不同来源的冲突强行改成一致，也不能增加来源不支持的新事实。

## 完成标准

新笔记具有统一、连贯的文章结构，能够追溯全部来源，原笔记保持不变，且重要内容没有因“总结”被过度压缩。
