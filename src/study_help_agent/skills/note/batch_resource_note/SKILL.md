# 批量独立资源笔记

## 适用条件

用户一次提供 2～20 个彼此独立的链接或复杂资源，例如多个视频、PDF、图片或混合格式文件。默认语义是分别处理，而不是把所有来源强行合成一篇。

## 标准步骤

1. 整理来源列表并保持用户给定顺序。
2. 只调用一次 `build_learning_notes_batch`。该工具内部会让不同来源以有界并发推进获取、提取、质量检测、按需清洗和笔记生成，并保留单项失败。
3. 检查返回的 `items`、`success_count`、`failure_count`、阶段状态、缓存命中和 warning；不要再次手工调用已经封装的底层步骤。
4. 根据每个成功项的 `title`、`introduction`、`core_topics` 生成最终回答；按来源概括内容并提炼 2～5 个核心要点。
5. 对失败项说明失败阶段和原因。批量工具已经处理有限重试，不要让外层 Loop 对同一失败来源无界重试。

## 并发与数据边界

批量流水线按资源并发，允许一个资源进入笔记生成时另一个资源仍在提取或重试。并发上限、阶段依赖、缓存与取消传播由程序控制，不由 LLM 手写异步依赖。若用户要求把不同来源统一为一篇，但主题范围、顺序或冲突处理不明确，应先确认，不能默认拼接。

## 完成标准

每个成功来源都有独立、可追溯的提取结果和笔记；每个失败来源都有明确原因和处理结论。最终回答已经对每个来源的主要内容和核心知识点作出简洁总结。
