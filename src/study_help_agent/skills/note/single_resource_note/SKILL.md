# 单资源笔记

## 适用条件

用户给出一个本地文件或外部链接，并希望生成一篇或一组围绕该资源的学习笔记。用户直接粘贴了完整文本时不需要资源获取，直接进入笔记构建。

## 标准步骤

1. 对一个链接或本地资源只调用一次 `build_single_learning_note`。工具内部完成获取、提取、确定性质量评估、按需清洗、笔记生成和保存。
2. 检查返回项的阶段状态、缓存命中、warning、笔记标题、内容简介和核心知识点。
3. 再执行一轮 `finish`：最终回答应给出笔记标题、来源内容概括和 2～5 个核心要点，不能只报告文件已经保存。

## 异常处理

获取失败时确认链接有效性、平台支持和本地路径权限；提取为空时不要继续生成空笔记。音频或视频只有部分内容可用时，应把 warning 传入后续判断并在最终结果中说明覆盖范围。

## 完成标准

笔记必须可追溯到唯一来源，保留来源名称、URI、类型和生成时间，并忠实覆盖资源中的主要知识内容。
